Como funciona Sem emulador, sem ROM, sem instalação

🧩

Motor reimplementado

Nada de emulação: o jogo foi reescrito em Rust do zero, lendo os formatos originais (PBG3, ANM, ECL, STD, MSG) e interpretando os scripts de bullet pattern do jogo original.

📦

Compilado para WebAssembly

O motor vira um módulo .wasm que o navegador executa a 60 Hz com passo fixo — igual ou melhor que o jogo original de 2002, e independente do refresh do seu monitor.

🔒

Seus arquivos ficam na sua máquina

O portal não hospeda os arquivos do jogo. Você seleciona a pasta uma vez no seu PC; os bytes são lidos localmente, ficam em cache no navegador e nunca são enviados para nenhum servidor.

Direitos: este é um projeto de fã, sem vínculo com a Team Shanghai Alice. O motor é de código aberto (MIT) e não distribui nenhum arquivo do jogo — ele precisa que você tenha uma cópia legítima do Touhou 6 (v1.02h / patch inglês th06e) para funcionar.
