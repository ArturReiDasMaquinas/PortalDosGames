Como trocar os links

Edite o arquivo site-config.json na raiz do repositório e troque os campos links.th06.url e links.flash.url. O portal lê esse JSON no carregamento e preenche todos os botões, cards e links do site. Se o JSON falhar ao carregar, o site continua funcionando com os valores padrão — nada quebra. 

{
  "links": {
    "th06":  { "url": "https://seu-usuario.github.io/TH06-web/" },
    "flash": { "url": "https://seu-site-flash.com/" }
  }
}
Dica: no GitHub Pages, um repositório publicado em https://user.github.io/repo/ pode ter atalhos extras para o mesmo código usando query strings — por exemplo jogos.html?jogo=th06 abre direto o site do Touhou 6 em vez de mostrar a lista.
